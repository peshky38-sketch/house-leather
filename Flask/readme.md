# Flask

## Projects

- `introFlask/` is for introductory Flask exercises.
- `orm/` contains the Flask + PostgreSQL inventory API and its setup guide.
- `serverSideRendering/` is for server-side-rendering exercises.

For the PostgreSQL project, follow [`orm/readme.md`](./orm/readme.md). It has a
separate Pipenv environment and uses a local, ignored `.env` file for database
credentials. Start from `.env.example`; do not commit or share `.env`.
