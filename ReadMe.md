# Learning projects

This workspace contains CSS, database, FastAPI, Flask, JavaScript, Python, and
React learning projects.

## Python API projects

- [FastAPI projects](./FastApi/readme.md) covers the introductory SQLite app
  and the separate PostgreSQL inventory API.
- [Flask projects](./Flask/readme.md) links to the Flask/PostgreSQL setup.
- [Database exercises](./DB/readme.md) contains database learning materials.

Each project has its own Pipenv manifest. PostgreSQL examples use a local
`.env` file, ignored by Git; create it from that project's `.env.example` and
never commit or share credentials.
